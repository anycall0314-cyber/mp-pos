# <系統代號> 統一互動關係

> 一個操作對其他資料的影響，一條一列。全系統一份。
> 「未觀察到」不寫在這裡，寫在模組檔的跨模組矩陣。

## 關係格式（不要改欄位順序）

| 關係ID | 觸發操作（模組 / 流程） | 來源（實體.欄位） | 影響（實體.欄位） | 影響方式 | 時點 | 作廢 / 刪除時 | 面向 | 標記 | 信心 | 證據 |
|---|---|---|---|---|---|---|---|---|---|---|
| REL-001 | | | | | | | | | | |

欄位說明：
- **影響方式**：新增、增加、減少、改狀態、寫入快照、重算、清除。
- **時點**：存檔當下、核准時、出貨時、日結、月結、手動觸發、不明。
- **作廢 / 刪除時**：回沖、不回沖、改狀態為…、不明。
- **面向**：庫存數量、IMEI / 序號、會員、交易紀錄、成本、毛利、佣金、應收帳款、財務報表（可多個）。
- 驗證方式：操作前後各查一次受影響的畫面；只查一次的標【推論】。
