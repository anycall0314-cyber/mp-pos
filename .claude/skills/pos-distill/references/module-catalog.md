# 模組代碼與必問清單

模組檔名：`modules/<NN>-<代碼>.md`（NN 照下表順序）。競品的模組切法跟下表不一樣時，照下表歸類，
在模組檔第 0 節寫「競品原本的選單名稱與位置」。一個競品畫面橫跨兩個模組，主模組放完整內容，另一個模組只放連結。

| NN | 代碼 | 模組 | MP POS 對應（app） |
|---|---|---|---|
| 01 | PRD | 商品主檔（品號、品名、類別、品牌、機型、相容配件） | `catalog`、`identity` |
| 02 | STK | 庫存與序號（數量、IMEI / SN、狀態、盤點、快照） | `inventory`、`ledger` |
| 03 | PUR | 進貨（含贈品、運費、付款、作廢） | `purchasing`、`vendor_orders`、`identity`（智慧入庫） |
| 04 | SAL | 銷貨（開單、付款拆分、發票、作廢） | `sales` |
| 05 | RTN | 銷退與換貨 | `sales`（`SalesReturn`） |
| 06 | TRF | 調撥 | `transfers` |
| 07 | MBR | 會員與客戶來源 | `parties`（`Member` / `Customer`） |
| 08 | TEL | 門號、SIM 卡、電信方案、佣金、合約到期、代收話費 | `parties`、`sales`、`cash` |
| 09 | RPR | 維修 | `repairs` |
| 10 | USD | 中古機收購與銷售 | `inventory`、`purchasing`、`sales` |
| 11 | CSH | 現金、雜支、營業日報 | `cash`、`sales/daily_report.py` |
| 12 | ARP | 應收應付、月結、同業往來 | 只有批發往來帳（`trade/payments.py`：逐單欠款、收款由舊到新分、溢收）；沒有門市客戶月結、廠商應付、帳齡、對帳單 |
| 13 | IVC | 發票（字軌、取號、作廢、電子發票） | `tenants`（`InvoiceTrack`）、`sales` |
| 14 | RPT | 報表與分析 | `analytics`、各 app 的 report |
| 15 | ACL | 帳號、角色、權限、門市鎖定 | `tenants`（`UserProfile`、`abilities.py`） |
| 16 | CFG | 公司與門市設定、付款方式、單據規則 | `tenants`、`inventory`（`Warehouse`） |
| 17 | TNT | 多門市、多公司、總部與加盟 | `tenants`、`core` |
| 18 | B2B | 批發與同業買賣、廠商叫貨 | `trade`、`vendor_orders` |

## 每個模組都要問

- 入口在哪、幾層、幾個畫面完成一件事、點幾下、打幾個字。
- 用彈出視窗還是就地展開；切換畫面會不會遺失已填資料。
- 搜尋能打什麼（品名 / 品號 / 條碼 / IMEI / 電話）、模糊或精確、結果怎麼排。
- 單號規則、存檔後還能不能改、作廢與刪除的差別、作廢後連動回到哪裡。
- 多門市：看得到別家門市嗎？店員被鎖在自己門市嗎？
- 權限：哪些動作要主管？主管怎麼核准（同一畫面輸密碼、另一個帳號、事後核准）？
- 這個操作會動到哪些跨模組面向（庫存、序號、會員、交易、成本、毛利、佣金、應收、報表）。

## 各模組加問

**PRD 商品主檔**
- 品號是人訂還是系統產生？品名、規格、類別、品牌、型號、容量、顏色怎麼拆？
- 同一款不同容量 / 顏色是一個品號還是多個？配件怎麼對應手機型號（一對一 / 多對多）？
- 新增時怎麼防重複？停用與刪除？用過的商品能不能改「要不要追蹤序號」？

**STK 庫存與序號**
- 序號狀態有哪些？IMEI 與 SN 各自怎麼存？一台兩個 IMEI 怎麼辦？
- 可用 / 保留 / 調撥中 / 維修中怎麼分？能不能負庫存？
- 盤點流程、差異誰核准、盤點中能不能繼續開單？

**PUR 進貨**
- 贈品（買十送一）怎麼表示？計價數量與進貨數量？
- 成本怎麼算（含稅 / 未稅、運費攤提、加權平均或個別成本）？
- 付款方式與現金連動；作廢的條件（已賣出的怎麼辦）。

**SAL 銷貨**
- 開單步驟順序（會員 → 商品 → 價格 → 付款 → 發票），哪一步可以跳過？
- 付款拆分、找零、訂金；改價權限與底價。
- 刷 IMEI 是否自動帶商品與價格？上次成交價？
- 門號商品怎麼選方案、門號、卡號？佣金在哪一步出現？
- 送出前後各有幾次確認？作廢的連動。

**RTN 銷退**
- 整張退或逐筆退？換貨怎麼做？退回的機器狀態？發票折讓或作廢？

**TRF 調撥**
- 一步完成或派發 / 確認兩段？在途時的庫存歸屬？成本跟著走嗎？

**MBR 會員**
- 會員主鍵（電話 / 身分證 / 會員編號）？重複會員怎麼防？
- 消費紀錄怎麼查（電話、IMEI 反查）？點數、等級？

**TEL 門號與佣金**
- 方案屬於哪家電信？新辦 / 續約 / 攜碼怎麼分？綁約月數、到期提醒？
- 佣金有幾種（門市、業務員、公司實收）？什麼時候入帳？退約怎麼回沖？
- SIM 卡押金、卡號管理？代收話費進不進營業額？

**RPR 維修**
- 單據狀態流、自修與委外、零件領用與成本、保固期、返修、解鎖資訊保護。

**USD 中古機**
- 收購單據形式、個人收購的身分資料要記什麼（只記欄位）、成色等級、個別成本、上架售價。

**CSH 現金**
- 每日現金怎麼算、雜支、現金調整、跨日結帳、營業日報的組成。

**ARP 應收應付**
- 有沒有月結客戶與廠商？沖帳方式（逐單 / 由舊到新）？帳齡表？對帳單？

**IVC 發票**
- 字軌設定、取號時點、二聯 / 三聯 / 電子發票、作廢與折讓、統編怎麼帶。

**RPT 報表**
- 每張報表的維度、指標、期間、篩選、匯出；數字從哪張單來、作廢單算不算。
- 毛利用哪個成本？佣金是否計入營收？

**ACL 權限**
- 角色種類、功能勾選粒度、門市鎖定、敏感欄位（成本、毛利）誰看得到。

**CFG / TNT 設定與多公司**
- 哪些規則各家可以自己設？總部與門市的權責？跨公司資料隔離怎麼看出來？

**B2B 批發**
- 同業下單、價目、出貨、收款與欠款；跟一般銷貨的差別。
