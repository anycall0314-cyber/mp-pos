# 發票機(WP-103)測試步驟

> 給門市照著做的。這一頁目前只有「測試」:確認電腦連得上發票機、每一行印在紙上的哪裡。**開單之後自動印發票還沒有做**(下一步)。
>
> **哪些是驗過的**:系統排出來的每一行、送給機器的內容(用程式核對過)。
> **哪些還沒驗過**:實機。這台開發機沒有發票機,所以連線、速率、每一行落在紙上第幾行,都要靠你印出來拍照才知道。

## 這台機器

- WP-103:九針撞擊式,印三聯式收銀機發票(整捲複寫紙、號碼已經印在紙上)。
- 用 USB 接電腦。Windows 把它認成 **COM1**(裝置管理員「連接埠」底下的 `Prolific USB-to-Serial Comm Port`)。
- 系統用 Chrome 直接把要印的字送進 COM1,**不用裝驅動程式**。只有電腦版的 Chrome 或 Edge 可以。

## 測試之前

1. **把舊系統關掉**。一個 COM 埠同一時間只能給一個程式用,舊系統開著,新系統會連不上。
2. 測試會印在真的發票紙上,**每印一次用掉一張發票**。印出來的那幾張寫上「作廢」留著。
3. 測試完到「系統設定 → 業務設定 → 發票字軌」按那條字軌的**跳號**,填紙上的下一張,把系統對回來。

## 步驟

1. 在**接發票機的那台電腦**用 Chrome 開系統 →「系統設定」→「發票機台」。
2. 按**選發票機**。瀏覽器跳出一張清單,選 `COM1`(名字裡有 Prolific 或 USB-to-Serial 的那一個),按「連線」。旁邊會變成「已選」。這台電腦之後會記得。
3. 按**行號測試**。發票機會印滿一張:每一行最前面是行號(01 ~ 33),後面是一把尺(每 10 格寫 1、2、3)。
4. **把印出來的那一張拍照給我**(整張、拍正)。我要從照片上看:
   - 紙上印好的「日期:」「買受人:」「銷售額:」「營業稅:」「總 計:」各落在第幾行;
   - 它們後面要從第幾格開始印;框的右邊界在第幾格。
5. 我照照片把位置對好之後,你再按**樣張測試**:會印一張假的發票(店名、金額都是假的)。看每一項有沒有對到紙上印好的字。
   - 整張偏上(字印到印好的標籤上面):把「上面空 N 行」加 1 再印。

## 印出來不對的時候

| 狀況 | 多半是 |
|---|---|
| 印出來是亂碼、或一堆奇怪的符號 | 速率不對。換一個「速率」(9600 / 19200 / 38400 / 4800)再印 |
| 按了沒反應,畫面寫「連不上發票機」 | 舊系統還開著;或 USB 線鬆了;或發票機亮紅燈(沒紙、卡紙) |
| 清單裡沒有 COM1 | 發票機沒開電源、或線沒接;接好之後重按「選發票機」 |
| 畫面寫「這個瀏覽器不能直接連發票機」 | 不是用電腦版的 Chrome / Edge |
| 中文印成 `?` | 那個字發票機裡沒有(簡體字、特殊符號);正常的繁體字都有 |
| 一張沒印完就跳到下一張、或印完沒有跳到下一張的開頭 | 拍照給我,這要調紙的長度 |
