# kcimos 自動送單 · 使用步驟

> 用店內的品名在 POS 叫貨,按一下,品項與數量自動進 kcimos、送出、訂單編號記回 POS。
> **登入 kcimos 是人做的**(帳號、密碼、驗證碼);其餘自動。送出前會給你看一次確認單,你按「確認送出」才送。

## 每台電腦做一次:裝書籤

1. Chrome 開 POS →「進貨入庫 → 廠商叫貨」→ 選 kcimos →「紀錄」。
2. 上面有一顆「kcimos 小幫手」。**用滑鼠把它拖到書籤列**(書籤列沒出現:按 Ctrl + Shift + B)。

測試站與正式站各有一顆(連的 POS 不一樣)。換到正式站的時候,把測試站那一顆刪掉、到正式站重拖一顆。

## 每一次叫貨

1. 在 POS 用店內品名叫貨(跟平常一樣),成立一張 `VO-` 單。
2. 在「紀錄」那一張單上按 **自動送單** → 開一個 kcimos 的分頁。
3. 還沒登入 kcimos:先在那一頁按一下書籤「kcimos 小幫手」(它會記住是哪一張單),登入,登入後**再按一次**書籤。
   已經登入:直接按書籤。
4. 跳出確認單:店內品名、kcimos 的品名、數量、kcimos 現在的單價(跟參考價不一樣會標紅)、合計、收件人、備註。
   看過沒問題按 **確認送出**;不要送按「取消返回」(放進購物車的東西會清掉)。
5. 顯示「已送出 · kcimos 訂單 SO…」就好了。回 POS,那張單會寫「已傳出」,廠商單號底下有 kcimos 的訂單編號。

第一次送單,確認單最下面會多一行紅字「這個 kcimos 帳號會綁到『某某店』」:之後這家門市只能用這個 kcimos 帳號送(登入別的帳號不送)。
綁錯了:管理員到「系統設定 → 叫貨串接」那一張卡片按「解除綁定」。

## 會遇到的情況

| 畫面寫 | 意思 | 怎麼做 |
|---|---|---|
| 購物車裡已經有 N 項 | kcimos 的購物車不是空的(之前放的) | 「清空再送」;或「取消返回」自己去 kcimos 看 |
| 不能送:另一張叫貨單…還沒確認 | 同一家門市前一張單還沒處理完 | 先把那一張處理完(見下面「待確認」) |
| 沒有送出:… | 送出之前就停了(數量對不上、帳號不對…) | 照寫的原因處理,回 POS 再按一次「自動送單」 |
| kcimos 沒有收這張單 | kcimos 明講不行(例:庫存不足) | 改一改再送 |
| **不確定有沒有成立** | 送出去了,但沒有收到 kcimos 的回答 | **不要再送**。到 kcimos 的訂單查詢找備註寫「MP POS VO-…」的訂單(見下面) |
| 已取消 · 這一次已經被別的分頁接手 | 同一張單在另一個分頁重新送了 | 這個分頁關掉就好,到另一個分頁繼續 |
| 訂單成立了,但讀不到訂單編號 | 成立了,只是編號沒拿到 | 到 kcimos 的訂單查詢找那一張,把編號填回 POS |
| kcimos 上有 N 張這張叫貨單的訂單 | 連線不穩,瀏覽器自己把送出重送了 | 聯絡 kcimos 取消多的;留下那一張的編號填回 POS |

## 待確認

POS 的叫貨單寫「送出中」或「待確認」= 送出去了但還不知道有沒有成立。這時候**不能再送**、也不能自己標已傳,同一家門市的別張單也先不能送。

- **送出中**(剛送出的 5 分鐘):小幫手可能還在等 kcimos 回答。這段時間「沒有成立」按不到 —— kcimos 的訂單查詢上還看不到,不代表沒有成立。
  多半幾秒鐘就會變成「已傳出」;小幫手那一頁有寫結果就照它寫的做。
- **待確認**(過了 5 分鐘還沒有結果):到 kcimos 的訂單查詢看有沒有備註「MP POS VO-(那張單號)」的訂單:
  - 有 → 在 POS 那張單的「kcimos 訂單編號」填它的編號,按 **訂單成立**(這一顆隨時可以按,不用等)。
  - 沒有 → 按 **沒有成立**(要按兩下)。這張單回到可以再送。

還原備份:還原到比較早的備份時,已經送進 kcimos 的單不會變回「還沒傳」(成立的還是成立、待確認的還是待確認)。
備份之後才叫的單還原之後不在 POS 裡了,但 kcimos 那邊的訂單還在 —— 那幾張要自己記得,不要重叫。

## 知道的限制

- 送出去就是真的訂單,POS 取消不了(「取消叫貨」只是 POS 這邊的記號),要取消請聯絡 kcimos。
- 金額以 kcimos 算的為準(確認單上的運費是照頁面的規則估的)。
- 連線在 kcimos 回答之前斷掉時,Chrome 會自己把同一個送出再送一兩次(kcimos 自己的網頁也一樣,小幫手管不到)。
  小幫手會去訂單查詢看,有重複會明講。
