2026-10-14 · 平台內的買與賣已經在測試站 · 對外的接法還沒做

用這套 POS 的經銷商可以互相買賣;外面的系統照同一份規格也接得進來。錢不經過平台,只管帳。

做到哪了

賣家那一半 測試站

批發設定、往來的同行、中古機進貨就上架、全新機與配件開放批發、收到的單、刷機出貨、收款記帳。

買家那一半 測試站

叫貨頁看得到同行、中古機一台一筆、下單、取消、查進度、到貨入庫(手機序號直接帶進來)。

對外的接法 還沒做

給不在這套 POS 的系統用的金鑰、網址、通知。規格跟平台內同一份。

維修串接 等智盛

查料、報價、進度。方向寫在專案的規格第 8 節。

賣家怎麼用

要做的事在哪裡幾步
開起來(一次)銷貨作業 → 批發單 → 設定開放批發選開 → 儲存
讓一個同行可以買批發單 → 同行帳發往來代碼 → 把八碼傳給對方
中古機上架進貨、收購的表單不用做:存檔就上架,批發價自動算
全新機、配件開放批發單 → 批發品勾「批發」
出貨批發單 → 待出貨直接刷那一台 → 出貨
找不到那一台那一行不出(按兩下),其餘照出
現場客人要被訂走的那一台照平常結帳系統問:賣給客人 / 留給同行
收到錢批發單 → 同行帳 → 收款填金額 → 記一筆

買家怎麼用

要做的事在哪裡幾步
加入(一次)系統設定 → 叫貨串接 → 加入同行輸入對方給的八碼 → 加入
叫貨進貨入庫 → 廠商叫貨選同行 → 中古機勾「訂」、其他填數量 → 送出
取消廠商叫貨 → 紀錄對方出貨之前:取消叫貨(按兩下)
貨到了紀錄 → 到貨入庫序號已經列好,不用再刷 → 確認入庫

管什麼、不管什麼

管

  • 誰可以跟誰買
  • 看商品與價錢
  • 下單、接單、出貨
  • 收貨入庫
  • 對帳:哪幾張單、多少錢、收了沒

不管

  • 錢:不收款、不付款、不抽成
  • 叫物流(只帶託運單號)
  • 開發票(只帶抬頭與統編給賣家)
  • 退貨與瑕疵換貨(這一版不做)

兩種身分、兩種接法

同一家經銷商可以同時是賣家與買家。買家以門市為單位:一間門市一個收貨地點、一份往來。

接法什麼時候用怎麼認人
平台內買賣雙方都用這套 POS不用金鑰。賣家在 POS 裡核准這個買家就通了
對外有一方不在這套 POS(別人的 POS、廠商自己的系統)賣家發一把金鑰給買家的一間門市

兩種接法是同一份規格,資料長得一樣。之後有經銷商換系統、或廠商要接進來,不用重談格式。

一張單的一生

買家 看商品→ 下單→ 收貨入庫
賣家 待接單→ 已接單→ 部分出貨→ 已出貨→ 已完成 已拒絕 已取消
  • 一張單可以分好幾次出貨,買家照每一次出貨收貨。
  • 手機、平板這類帶序號的,出貨時帶著每一台的序號。買家收貨直接變成自己庫存裡的那幾台,不用再刷一次。
  • 價錢只有賣家算。買家下單不送價錢,以賣家回的為準。
  • 同一張單只會成立一次。斷線了再送,不會變成兩張(現在叫貨就是這樣做的)。
  • 訂單現在的樣子以賣家那邊為準。賣家事後改單,買家再查就是新的。

誰看得到什麼

平台上的經銷商是互相競爭的,所以預設都收著。

買家看得到

  • 賣家開放給他的商品
  • 他自己的價錢
  • 他自己下的單

看不到賣家的成本、別的買家的價錢。

賣家看得到

  • 下給他的單
  • 那張單的收貨資料與聯絡方式

看不到買家的庫存、買家跟別家買了什麼。

沒被核准的買家,連這個賣家有沒有在賣都不知道。

共同語言

手機、平板、穿戴

用平台的標準機型。買賣雙方講的是同一支,買家不用連品名,直接對到自己的品號。

配件與其他

沒有共同語言。賣家給自己的料號與品名,買家用「品名連連看」連一次,之後自動。

管帳

  • 每張單有金額、付款方式(雙方講好的文字)、收款記號(賣家自己按:未收款或已收款)。
  • 對帳單:某一段期間跟某一個對象的每一張單、出貨金額、收了沒、合計。買賣雙方各拉各的,數字同一個來源。
  • 價錢含不含稅,每個賣家講清楚一次。
  • 不做收款沖帳、預收、抽成。

你定的八件事

誰可以跟我買

中古機:平台販售(平台上每一家同行都看得到;可以改成只給核准的)。全新機與配件:只給核准的同行,用往來代碼加入。

庫存露多少

只露有貨、缺貨。賣家可以改成露數量。

同一台被同行訂了、現場客人也要

出貨之前賣家可以抽回來賣給現場客人,同行那一台當下取消。

管帳

記一筆收到的金額,由舊到新銷單,看得到還欠多少。錢不經過平台。

買家取消

賣家出貨之前,買家可以自己取消還沒出的部分。

對外的金鑰

賣家自己在後台發。(還沒做)

平台內兩邊的單

賣家出貨自動開銷貨單、扣庫存;買家收貨開進貨單,手機序號直接帶進來。

維修串接

等智盛加入再排。

要先知道的

  • 賣出去的同一台再收回來,系統原本就還沒有。甲批給乙、乙之後又批回甲,甲入庫那一台會被擋。要另外排。
  • 手機現在要連一次品名(中古機連一次,每一台都算)。標準機型做好之後就不用連。
  • 出貨開的銷貨單付款方式是「同行記帳」,不算當日現金。收到錢在同行帳記。
