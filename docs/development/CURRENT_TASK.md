## 商品照片與手機拍照直傳(規格的 A / B / C 階段)

(對應 `BACKLOG.md` 進行中 B;規格:owner 給的 `MP-POS-商品圖片備註與手機拍照直傳規格.md`)

### 目標

新增 / 編輯商品時可以從電腦選照片、或用手機掃 QR Code 拍照直接傳進來;之後在商品管理、庫存查詢、進貨 / 銷貨選品與明細上,
點品名就能看照片與規格,確認是同一件就沿用既有品號,減少同商品被不同人重複建檔。

### 這一件的範圍

- A 商品圖片基礎:商品表單的「商品照片」區 —— 電腦選檔(可多選)、縮圖、放大、主圖、說明、排序、移除(儲存才生效)、失敗重試;
  新增商品還沒有品號就能先加;照片跟商品同一次存檔。
- B 手機直傳:電腦顯示 QR Code → 手機開拍照頁(不用登入、不用裝 App)→ 拍照 / 從相簿選 → 電腦照片區自動出現。
- C 選品核對:點品名看照片與規格的面板 —— 商品管理清單、庫存查詢、進貨 / 銷貨的搜尋結果與已加入的明細。
  搜尋結果裡看照片不會自動加入,另有「使用此商品」;已加入的明細只看不加。

後端(`backend/apps/photos/`)在訂這套流程之前已經做完、35 個測試過;這一件主要是前端,後端只在接畫面時發現問題才改。
