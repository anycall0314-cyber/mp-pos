## 商品管理搬到「進貨入庫」;建好品號可以直接去進貨

### 目標

建商品的下一步多半就是進貨:商品管理放在「進貨入庫」底下;品號建好之後按一下「進貨」,帶著這個商品到進貨開單頁,不用再搜尋一次。

### 我的理解(owner 沒有另外指定的地方,回報時講清楚)

1. **導覽**:「商品管理」這個分頁從「商品庫存」搬到「進貨入庫」(排在「進貨單」後面);右邊的「商品設定」選單(品牌系列 / 產品類型 / 商品品況)跟著一起搬。
   「商品庫存」剩下 庫存查詢 / 庫存警示 / 調撥作業。網址都不變;功能搜尋照樣找得到。
2. **進貨開單頁收得到「要進哪些商品」**:網址帶 `?add=商品編號,…`,打開時把那幾個商品加進明細(已經有進行中的草稿就加在草稿上),加完把網址上的參數拿掉(重新整理不會再加一次)。
   中古機不能走一般進貨(原本就擋):講出來、不加;停用的商品照原本的規則。
   **帶過來的配件數量先是 0**(還沒說進幾件;刷或打數量才算,0 存不了)—— 紅隊指出先放 1 的話再把每件刷一次會多進一件。
   沒加進去的原因留在明細上方(按「知道了」才消失)。
3. **商品管理**:商品詳情的「編輯」旁邊多一顆「進貨」;新增商品存好之後自動選到那一筆、並跳一句可以直接按「進貨」的提示。中古機的「進貨」帶去「中古收購」。虛擬商品沒有這顆。
4. **新增手機型號建完**:多一顆「前往進貨」,帶著這次建的品項(不含中古的)去進貨開單頁;有建中古的品項再多一顆「中古收購」;按鈕字數一致。
