## 條碼列印機(Argox OS-2130D)

(對應 `BACKLOG.md` P1「條碼列印機(Argox OS-2130D)」)

### 目標

門市用 Argox OS-2130D 印 50 × 30 mm 的商品標籤:進貨存完整張印、單一商品或某一台隨時補印、中古機一台一張(帶那一台自己的售價與成色)。
Mac 與 Windows 的 Chrome 都走同一條路(瀏覽器列印 + 各自裝原廠驅動);這一件先以 owner 手上那台 Windows 為準。

### owner 的決定(2026-10-06)

1. **標籤紙 50 × 30 mm。**
2. **三個地方都要能印**:進貨單整張印(已經有)、單一商品補印(在庫存查詢挑商品或某一台、自己打張數)、中古機逐台印。
3. **標籤上印**:品名、條碼,加上售價、序號末 5 碼、品號、進貨單號與日期。
4. **印表機已經有,接在 Windows 電腦**:做好之後由 owner 在那台電腦實際印一張確認。

### 我的判斷(已經跟 owner 講過 / 會在回報裡講)

- 印表機是熱感式 203 dpi、最寬印 72 mm;原廠有 Windows 驅動、也有 macOS 驅動(新款 Mac 要裝 Rosetta)—— 從原廠網站查到的,我接不到實機。
- **不直接對印表機下指令**:照舊用瀏覽器列印。兩種電腦同一套做法、不用另外裝程式;代價是每台電腦要裝一次驅動、設定一次紙張。
- **條碼的每一條線要剛好是印表機的整數個點**(203 dpi,一個點 0.125 mm):現在的列印頁是把條碼拉寬到貼滿標籤,線寬不是整數點,
  熱感印出來會糊、槍刷不到。改成自己照點數畫(一個單位 3 點,放不下用 2 點);2 點還放不下的碼(太長)只印文字、不印條碼,並在畫面上講出來。
- 條碼內容照舊:有序號印主碼(有 IMEI 印 IMEI,沒有才印 SN)→ 沒有序號印原廠條碼 → 都沒有印品號。
- 售價:一般商品印建議售價;逐台定價的(中古機、已拆封)印那一台自己的售價,沒有才印建議售價。成色只有逐台記機況的才印。
- 進貨單號與日期:序號商品印那一台當初進貨的單;個人收購進來的印收購那一張單;配件補印沒有「哪一批」可言,不印(不猜)。
- 標籤尺寸先寫在一個地方(前端 `lib/labels.ts`、列印樣式),不做成每家公司的設定;別家公司要用別的尺寸再加。
