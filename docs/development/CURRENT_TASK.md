## 門號合約到期的統計與提醒

(對應 `BACKLOG.md` P1「門號合約到期的統計與提醒」)

### 目標

門號合約快到期的客人,門市看得到名單、知道該聯絡誰、聯絡過的記下來;老闆看得到每個月有幾筆要到期。

### owner 的決定(2026-10-07)

1. **提醒只在系統裡**:「電信作業」多一頁「合約到期」名單;「今日總覽」顯示幾筆待聯絡,點了到名單。不推通知。
2. **到期前 3 個月**開始出現在名單上(系統設定裡可以改)。
3. **聯絡過的要記**:每一筆可以標「已聯絡」或「不續約」、加一句備註;標「不續約」的不再出現在待聯絡。
4. **上線前就辦的舊客戶先不管**:只管用這套系統賣出去的門號。

### 規則(我的判斷,已經跟 owner 講過)

- 一筆門號合約 = 一行有方案、有合約到期日的銷貨明細(到期日 2026-10-06 起存檔當下算好)。
- 同一個門號有比較新的合約 → 舊的那一筆算「已續約」,不再提醒。
- 整張銷退、作廢的銷貨單上的門號不算(舊資料只退其中幾行的:只有被退的那幾行不算)。
- 「同一個門號有比較新的合約」只認另一張單;門號欄是「-」「無」這種沒有數字的不拿來比。
- 打了沒人接可以只記備註,人還留在待聯絡;按「未聯絡」改回來時備註留著。
- 過了到期日還沒續、也沒標「不續約」的,繼續留在名單上(標成過期幾天)。
- 鎖在自己門市的店員只看得到自己門市賣的;管理員看全部。
- 統計(每個月幾筆到期,依電信業者 / 方案種類 / 門市 / 業務員)放進「統計分析 → 自由組合」:加一組指標與角度,不另外寫報表頁。
