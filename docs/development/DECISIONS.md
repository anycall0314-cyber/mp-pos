# DECISIONS

重要的商業與設計決策**全文記在 [`docs/decisions.md`](../decisions.md)**(一則一段:背景、決定、取捨),不在這裡另開一份,
免得兩邊各寫各的。新的決策照下面的格式加在那一份的最後,這裡只留索引。

```md
## 日期:標題
Decision:(決定了什麼)
Reason:(為什麼)
Impact:(哪些地方要跟著這樣做)
```

## 索引(最常被問到的幾則;其餘見 `docs/decisions.md` 與 `CLAUDE.md` 的「業務規則速查」)

| 主題 | 一句話 |
|---|---|
| 儲存即生效 | 單據沒有「過帳 / 未過帳」,存了就生效,要取消用作廢 |
| 成本 | 全公司加權平均(不分倉);中古機每一台用自己的收購成本 |
| 計入現金 / 計入毛利 | 兩個旗標分開:收購二手算現金流出、不算毛利 |
| 金額 | 單據金額一律整數元、四捨五入;成本照舊算到分 |
| 銷退 | 只能整張退,金額與成本照抄原單 |
| 設備的碼 | 一台可以有 IMEI、SN 兩個碼;同一家公司一個碼只屬於一台;作廢的設備不佔碼 |
| 改庫存 | 先鎖、再檢查、再改 |
| 報表 | 指標與角度只有一套定義(`apps/analytics/catalog.py`);銷售類指標只算計入毛利的明細 |
| 同一份建單只成立一次 | 進貨單、銷貨單認得 `Idempotency-Key`(尚未上線,見 `BACKLOG.md` 進行中 1) |
| 門號合約日期 | 合約從續約日 / 生效日起算,到期日存檔當下算好(尚未上線,同上) |

## 還沒有定案、要 owner 決定的

- 商品營業額、維修收入、電信佣金、保險佣金在報表上要分開顯示到什麼程度(計畫 Phase 05)。
  現況:佣金存在銷貨明細上、算進毛利;還沒有「佣金應收 / 撥款」。
