## 技術債(發現了先記著,不順手改)

- (商品照片複審的「建議」,沒有在這一批修)大張、用「某一個顏色當透明」的 PNG 縮圖後透明的地方會帶一點灰(先縮才轉透明;一般照片不受影響)
- (同上)做公司備份的當下剛好有人移除商品照片:那一次備份會因為檔案不見而失敗(不會做出缺檔的備份,重做一次就好)→ 之後讓刪檔跟備份錯開
- (同上)手機拍照頁斷線時按「移除」:手機上那一張會消失,但電腦那邊還在,沒有「移除中 / 沒移除成功」的提示(電腦上可以自己移除)
- (同上)進貨開單頁的「勾選商品」「批次貼上」兩個面板裡還不能看照片

- (Codex 第三輪的「建議」,沒有在這一批修)進貨開單頁的掃碼框沒有跟著供應商 / 入庫倉 / 換一張單重設:
  查到一半換供應商,舊條件的結果還可能落回畫面;清空草稿之後,上一張的「沒加入」可能繼續擋下一張
- (同上)銷貨單清單上「方案」那段字顯示的是方案主檔現在的月數;方案改過月數之後,舊單的到期日是對的(照當初的月數),
  但那段字會寫成新的月數,兩個看起來矛盾 → 改成顯示明細上抄下來的月數

- (門號合約到期 Codex 第二輪的「建議」,沒有在這一批修)聯絡紀錄的端點收到不是文字的狀態 / 備註(`status: true`、`note: 123`)會回 500 而不是 400(畫面不會這樣送)
- (同上)「合約到期前幾個月」收到 `1.9` 或 `true` 會被當成 1 存起來(畫面會擋;保固天數本來就有一樣的寬鬆)→ 拒絕布林與非整數
- (同上)「標記存好、重讀之前那張單剛好被作廢」回 400 的那個分支還沒有測試直接驗到(修正本身複審看過)
- (同上,前端)合約到期那一頁打了還沒存的備註,點單號去看原銷貨單再回來就不見了(那一格有標「未存」)→ 原單另開分頁,或離開這一頁時把草稿留著
- (門號合約到期的紅隊意見,沒有在這一批修)斷線時的錯誤訊息是英文(`Failed to fetch`):共用的 `apiErrorText` 對「連不上」沒有白話句子,全站都一樣
- (同上)系統設定的「保固天數」存失敗沒有任何提示(這一批只補了旁邊「合約到期前幾個月」那一格)
- (同上)自由組合報表不鎖門市(本來就這樣):鎖倉店員在報表看得到全公司的到期門號數;名單頁有鎖
- (同上)合約到期的備註 200 字,輸入框沒有顯示還剩幾個字

- (條碼列印機 Codex 第二輪的「建議」,沒有在這一批修)標籤列印頁上面改配件張數時打了範圍外的數字(例如貼上 501)再按「列印」:
  那一格一離開會先退回上一個數字,印的是上一個數字(庫存查詢的補印按鈕已經擋了,列印頁還沒有)。畫面上的「共 N 張」是對的
- (做條碼列印機時發現的)**有一個測試偶爾會失敗**:`apps.photos.test_photos.EditExistingTests.test_cancelling_the_edit_leaves_saved_photos_alone`
  拿「取消前」與「取消後」兩次查到的照片清單整包比,清單裡的照片網址帶著以秒為單位的簽章 —— 兩次查詢剛好跨過一秒,網址就不一樣、測試就紅
  (功能沒有問題,是測試的比法;2026-10-06 晚上四次完整測試裡出現兩次)。改法:比照片的編號 / 順序 / 說明,不比網址
- (做條碼列印機時發現的)全站樣式有三條沒有名字的 `@page`(標籤、80 mm 收據、A4 維修單)互相蓋,最後生效的是 A4:
