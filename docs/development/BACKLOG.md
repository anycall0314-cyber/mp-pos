  管理員把含公司佣金的報表設成全公司共用時,店員打不開、但清單上看得到那個指標的代碼(看不到金額)。

- **商品業務員成本的後續**(2026-10-09 記;加成從全公司的平均加是 owner 選的,不是待辦):
  規則沒有生效日期、沒有修改紀錄(誰在什麼時候把加成改成多少);不能照類別 / 品牌設(只有全公司與單一商品,批次修改可以一次套一批);
  庫存查詢、維修的毛利還沒有業務員成本這個數字;開單頁剛刷進來的中古機在清單載回來之前用商品的數字估;
  管理員的實際毛利只在銷貨單清單上,日報與報表沒有含公司佣金的那一個。
  帶序號的商品先不做(owner 2026-10-10;開關 `staff_cost.SERIAL_GOODS_TOO`):之後要做時,開單頁手機的預估用的是平均成本、存檔記的是那一台的實際成本,要一起看。
  商品表單只看「需追蹤序號 / 虛擬商品」兩個勾來決定要不要顯示那一段:類別是中古機類別、兩個勾都沒勾時那一段還在,填了伺服器不會存(存完詳情就沒有那一列)。

- **員工帳號權限的後續**(2026-10-10 記):沒有修改紀錄(誰在什麼時候關了誰的哪一項);權限變更之後店員已經開著的畫面要重新整理才收按鈕(伺服器當下就擋);
  雜支 / 現金調整 / 代收話費現在不能刪除只能作廢,但「編輯」還是誰都可以(金額改成 0 也算一種繞過;第二批「進貨與現金帳務」一起看);
  帳號的新增 / 停用 / 密碼還是只有平台管理員能做(公司管理員自己管不了人)。
