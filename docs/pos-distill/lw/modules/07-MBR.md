# lw · 07-MBR 會員 — 會員客戶管理（初步）

## 1. 畫面
查詢：系統業者、單位、資料來源（門市銷售／立穎待上線／資費繳款）、門號、上線日期、ID號碼、合約到期日、「合約到期日為空值」。表頭：會員名稱、系統業者、門號、上線日期、上線專案、合約到期日。FD-MBR-001～004。【事實】EV-027

## 推論
會員主鍵偏向「門號合約」而非「人」：一人多門號多列。合約到期日是續約提醒的依據（與銷售管理的「客戶續約上線查詢」相關）。

對照 MP POS：`Member` 是人，門號與到期在銷貨明細（`sales/models.py:277-285`）＋ `ContractFollowUp`；MP POS 已把兩者分開，較合理。可借鏡的是「合約到期日為空值」這類資料品質篩選。
