# lw · 12-ARP 應收應付 — 應收帳款與門號佣金往來帳

## 0. 位置
帳務管理（8 功能）：門號佣金應收帳款(收款)／(銷帳)、手機補貼管理／入帳管理、掛招商帳務進度管理、應收帳款(收款)管理、應收帳款-對帳單、會計派工管理。【事實】EV-018

## 1. 畫面
- 應收帳款(收款)：清單＋每列勾選的批次收款列（收款日期、收款部門）；表頭見 FD-ARP-001～008。業務角色：編輯／刪除停用，勾選框存在（是否能收款未測）。【事實】EV-018
- 門號佣金應收帳款(收款)：同構，項目 29 種（FD-ARP-009）。【事實】EV-019
- 對帳單：報表頁，彙總／明細。【事實】EV-020

## 2. 流程（推論）
FL-ARP-01：出貨單完成 → 產生應收（貨款）→ 以客戶可出貨額度抵一部分（使用額度）→ 剩餘＝應收金額 → 收款（填日期、部門）→ 銷帳。【推論】依 FD-ARP-004、006、007；Q-026、027
FL-ARP-02：門號件開通／退件／切結／調改… → 在佣金往來帳產生對應正負項目 → 收款 → 銷帳。【推論】依 FD-ARP-009；INF-018
