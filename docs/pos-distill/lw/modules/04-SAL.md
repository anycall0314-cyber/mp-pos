# lw · 04-SAL 銷貨 — 門市營業銷貨單（第二帳號觀察）

## 0. 位置
銷售管理 › 門市營業銷貨單管理（舊）、新門市營業銷貨單管理（新）、新門市營業銷貨單捷徑（9 入口）、門市退貨管理、每日結帳。【事實】EV-024～027
此帳號（立穎竹北倉，倉／門市權限）看得到清單與明細，但開「新門市銷售」被擋（no_authority）。【事實】EV-026

## 1. 畫面
- 清單：查詢只有單位／人員與單號；表頭含現金／刷卡／分期／銷售金額／現金退款／發票號碼／狀態；舊版有刪除、新版沒有。FD-SAL-001～005。
- 明細：單頭 24 個標籤（含毛利、三個關聯單號、多付款、利息類型）＋明細（序號／項目／銷售說明／售價）。FD-SAL-006～010。
- 捷徑頁：9 個磚（商品銷售／客戶退貨／客退換貨／欠客商品／退款／維修／每日結帳／自購／新門市銷售），每個附一句說明。FD-SAL-011、012。
- 操作成本：開一張單要先進捷徑頁選入口（1 畫面）再進表單；查一張單：清單 1 ＋ 明細 1。

## 2. 流程（推論，依捷徑說明）
- FL-SAL-01 商品銷售：輸入上線門號／單獨商品／門號+手機 → 付款（現金、刷卡、分期）→ 發票 → 存檔；狀態「全額支付」或「付訂金」。
- FL-SAL-02 客戶退貨：刷序號即退；換貨要先退再賣（客退換貨要併退貨單號）。
- FL-SAL-03 退款：對現金訂金或刷卡退款。
- FL-SAL-04 每日結帳：每人每日結算；結帳後當日不能再銷貨、退貨、退款。
- FL-SAL-05 欠客：缺貨先收款，欠客單號追蹤；毛利統計可排除。Q-031。
- FL-SAL-06 自購：員工購機另一入口。
