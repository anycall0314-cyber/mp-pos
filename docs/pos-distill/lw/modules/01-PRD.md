# lw · 01-PRD 商品主檔 — 手機別名／型號

## 0. 位置
產品管理（4 功能）：手機別名管理、手機型號管理、配件型別管理、手機POS紀錄查詢。【事實】EV-021

## 1. 畫面
- 手機別名管理：清單（廠牌／類別名稱／手機名稱／編輯）；查詢含產品類別 4 種、手機類別 8 種、停售／正常。新增、編輯可用；刪除停用。
- 手機型號管理：清單（廠牌／編號／型號名稱／銷售狀態／編輯）；查詢含「含已刪除資料」。
- 型號編輯頁：10 個欄位（FD-PRD-006～011），儲存鈕。
欄位 FD-PRD-001～012。【事實】EV-021

## 結構（INF-019）
廠牌 → 手機別名（機種；產品類別、手機類別、停售）→ 手機型號（變體；型號編號人工、國際條碼、最大銷售量、門市庫存、清倉、補貨、可上載圖檔、銷售狀態）。
對照 MP POS：Brand → PhoneSeries → PhoneModel → Product（容量、顏色分欄，sku 系統產生不輸入）。差異：lw 型號編號人工輸入；lw 有「補貨 Yes/No」「清倉」「門市庫存上限」三個補貨相關旗標在型號層。
