# EV-lw-20261017-021 報表專區（cat_id=13）與 產品管理（cat_id=3）

報表專區：此業務帳號左側無任何功能（空白）→ 角色限制。
產品管理功能（4）：手機別名管理、手機型號管理、配件型別管理、手機POS紀錄查詢。

手機別名管理 /cellphone_name_edit.aspx：查詢＝手機廠牌、未設定手機介紹、名稱、產品類別（GSM／CDMA／LTE(4G)／3C商品）、手機類別（一線手機／二線手機／亞太手機／3C商品／筆電／相機／導航機／平板電腦）、狀態（停售／正常）；新增可用。表頭：廠牌｜類別名稱｜手機名稱｜功能（編輯可用、刪除停用）。
手機型號管理 /cellphone_model_edit.aspx：查詢＝廠牌、名稱、銷售狀態 Yes/No、含已刪除資料。表頭：廠牌｜編號｜型號名稱｜銷售狀態｜功能（編輯可用、刪除停用）。
型號編輯頁 /cellphone_model_add.aspx 欄位：手機別名（≤255）、型號編號（≤30）、國際條碼（≤50）、手機型號（≤100）、最大銷售量（≤30）、門市庫存（≤30）、清倉狀態 Yes/No、補貨 YES/No、可上載圖檔 Yes/No、銷售狀態 Yes/No、儲存鈕（未按）。
→ 三層：廠牌 → 手機別名（機種，帶產品類別與手機類別）→ 手機型號（容量／顏色變體，帶型號編號與國際條碼）。
