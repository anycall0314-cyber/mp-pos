# EV-lw-20261017-020 應收帳款-對帳單 /accounts_receivable_checklist.aspx 與 手機補貼管理 /cellphone_subsidy_edit.aspx

對帳單（報表）：客戶名稱、銷售日期起迄、收款日期起迄、銷售模式（正常銷售；特殊專案(明細表專用)）、客戶類別（經銷客戶／掛招店；東訊出貨）、區域（北／中／南）、狀態（未收款／已收款／全部）、收款部門（同 EV-018 八個）、報表種類（彙總表／明細表）、預覽。
手機補貼管理：補貼年月（民國年＋月）、補貼手機（別名）、補貼內容（文字）、新增鈕可用；表頭：補貼年月｜補貼手機｜補貼內容｜功能（編輯可用、刪除停用）；清單內容有連到附件的連結文字（「如附件」「神腦三星折讓」）。另有「手機補貼入帳管理」未看。
→ 手機補貼＝原廠／通路按月給的機型補貼，記在月表，再「入帳」。
