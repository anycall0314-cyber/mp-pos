# EV-lw-20261017-013 卡片佣金套餐明細管理、客戶佣金設定管理（DOM 與表頭）

卡片佣金套餐明細管理 /phone_card_brokerage_package_list_edit.aspx
- 查詢：電信業者（必選，無空白）、套餐 PhoneCardBrokeragePackageCode（CHA、CHA+、CHB、CHC、YCNA、YCNA (掛招)、YCNA+、YCNB、YCNC …）、日期（民國年 98～116 ＋ 月）、專案名稱、啟動代碼 init_code。
- 表頭：年份｜月份｜電信業者｜套餐代碼｜專案名稱｜佣金。
→ 佣金表 ＝ 年月 × 電信 × 套餐 × 專案 → 金額。

客戶佣金設定管理 /customer_brokerage_pakage_list_edit.aspx
- 查詢：電信業者、申辦類別 PhoneCardApplyCat（新申辦、NP、續約、預付卡、加掛、換補卡、行動裝置保險、服務異動）、日期（年 98～112 ＋ 月）、客戶名稱；有「新增」鈕（未按）。
- 表頭：客戶名稱｜電信業者｜申辦類別｜年｜月｜套餐｜更新日期｜人員｜（刪除停用）。
→ 客戶 × 電信 × 申辦類別 × 年月 → 套用哪個套餐。
