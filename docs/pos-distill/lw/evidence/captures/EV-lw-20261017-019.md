# EV-lw-20261017-019 門號佣金應收帳款(收款) /phone_card_check_receivables_edit.aspx

查詢列：客戶名稱、門號、帳款日期起迄、卡號、營業區域（北／中／南）、金額、收款項目（29 種，見下）、狀態（已收款／未收款）、筆數、客戶類別（經銷商／掛招店／門市）。
收款項目 29 種：收件付款、抽件、退件、差額、專案價收款、店內加碼、切結收款、切結手續費、切結付款、預繳金額收款、調改收款、調改手續費、調改付款、回件付款、取消調改、回件扣款、系退收款、查核付款、手機折讓、廢卡付款、上線數獎金、逾期扣款、Fraud扣款、Fraud退佣、NP加碼、網開紙加碼、退款、其它、客訴扣款。
表頭：（勾）｜客戶名稱｜區域｜門號／卡號｜收款項目／帳款日期｜佣金／實收金額｜收款人員／收款日期｜銷帳人員／銷帳日期｜收款狀態｜功能（編輯／刪除停用）。另有「收款小計」與收款日期（停用）。
→ 門號佣金是一本獨立的往來帳：每個門號件可產生多筆正負項目（付款＝付給客戶、收款／扣款＝向客戶收），同樣分收款與銷帳兩步。
