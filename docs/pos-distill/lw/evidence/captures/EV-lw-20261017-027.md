# EV-lw-20261017-027 每日結帳、門市退貨管理、會員客戶管理、門市毛利統計表、門市資費結算（查詢列與表頭）

每日結帳 /retail_daily_checkout_by_staff_edit.aspx：查詢＝結帳日期起迄、單位群組、單位名稱→銷售人員（連動）、姓名、結帳狀態（已結帳／未結帳／溢收／短收）、新增、匯出。
表頭：結帳日期｜單位名稱｜銷售人員｜現金｜刷卡｜分期｜違約金｜資費總額(含違約金)｜儲值｜銷售總額｜應繳金額｜實收金額｜短收｜溢收｜是否結帳｜編輯／刪除。→ 結帳以「人」為單位，不是以門市。

門市退貨管理 /returned_retail_sale_edit.aspx：查詢＝退貨門市、退貨單號、序號、退貨日期；新增。表頭：退貨單號｜銷售單號｜退貨門市｜退貨人員｜退貨日期｜列印｜編輯／刪除。

會員客戶管理 /member_edit.aspx：查詢＝系統業者（5 家電信）、單位名稱、資料來源（門市銷售／立穎待上線／資費繳款）、門號、上線日期起迄、ID號碼、合約到期日起迄、「合約到期日為空值」；新增、匯出。
表頭：會員名稱｜系統業者｜門號｜上線日期｜上線專案｜合約到期日｜編輯／刪除。→ 會員＝門號合約，一人多門號多列（推論）。

門市毛利統計表 /retail_sale_margin_statistics.aspx：銷售日期、門市群組、門市／人員、毛利金額（比較子 < <= > >=）、銷售產品（手機／配件＋品名）、產品類別（手機／手機+門號／配件／贈品／欠客）、排除合併欠客銷貨單、匯出。

門市資費結算 /retail_fee_checkout_edit.aspx：門市名稱、結帳日期；表頭：結帳日期｜門市名稱｜資費筆數｜資費總額｜審核人員。→ 門市代收電信資費另外結算。
