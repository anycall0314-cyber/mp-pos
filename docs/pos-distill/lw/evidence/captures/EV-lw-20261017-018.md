# EV-lw-20261017-018 帳務管理分類（cat_id=8）與 應收帳款(收款)管理 /accounts_receivable_edit.aspx

帳務管理功能（8）：門號佣金應收帳款(收款)、門號佣金應收帳款(銷帳)、手機補貼管理、手機補貼入帳管理、掛招商帳務進度管理、應收帳款(收款)管理、應收帳款-對帳單、會計派工管理。

應收帳款(收款)管理 查詢列：應收日期起迄、客戶類別（經銷商／掛招店，單選）、客戶名稱、金額、收款部門（聯歐通訊／台北／台中／高雄／週結／匯款／退卡／無部門，單選）、收款項目（出貨／退貨；另三個旗標：東訊出貨、聯強貨、大小聲出貨）、單號、銷售模式（正常銷售）、狀態（已收款／未收款）、筆數／頁。
批次收款列：每列一個勾選 select_status、收款日期 receivable_date（停用，推測勾選後才啟用）、收款部門 ROrganization 下拉。
表頭：（勾）｜客戶名稱｜區域｜收款項目｜單號｜應收日期｜收款日期／銷帳日期｜貨款金額／使用額度｜應收金額／實收金額｜銷帳｜功能（編輯／刪除：業務停用）。
→ 一張出貨單或退貨單對應一筆應收；「貨款金額」扣「使用額度」＝「應收金額」（推論，欄位並列）；收款與銷帳是兩個時點、兩個人。
