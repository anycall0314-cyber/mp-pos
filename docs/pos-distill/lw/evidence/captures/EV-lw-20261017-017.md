# EV-lw-20261017-017 分倉轉倉管理 /cargo_transfer_stock_edit.aspx 與 庫存查詢 /stock_all_search.aspx

分倉轉倉管理：查詢＝轉倉日期起迄、轉入單位 Organization（立穎各倉 ＋ 中祥）、狀態 transfer_status_0～2（轉倉中／已收貨／已退貨）、新增鈕 ctlAdd（業務角色可用，未按）。
表頭：轉倉單號｜轉倉日期｜轉倉單位｜轉倉人員｜轉入單位｜狀態｜功能（編輯／刪除：此角色可用，未按）。
另有「分倉轉倉收(退)貨管理」頁 → 兩段式：發出（轉倉中）→ 收貨（已收貨）或退回（已退貨）。

庫存查詢：三個分頁鈕 ctlA/B/C（手機／配件／卡片）、手機廠牌 → 手機型號（連動）、含展示機與模型機 checkbox、單位名稱（全部組織含門市與部門）、序號條碼、產品名稱、匯出。初始無清單。
