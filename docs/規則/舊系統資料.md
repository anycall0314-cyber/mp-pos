### 舊資料匯入指令

**正式站在 owner 明講「可以導入資料了」之前,不放任何舊 POS 的資料(owner 2026-10-10:「正式站在我把它寫完之前,都先不要跟舊pos有任何資料上的參與」)—— 舊會員、舊消費 / 十年歷史、舊庫存與品號、舊→新對照都算;這一列與下面「舊系統資料(歐睿)」那一列的指令一律只在本機與測試站跑,要對正式站跑任何一支都要先問。**2026-10-10 唯讀查過:正式站舊 POS 的表全部 0 筆。**`import_legacy_inventory --confirm` 會先把那家公司的銷貨 / 進貨 / 調撥單、序號、商品、類別、門市全部刪掉再灌**:只准對測試資料庫 `mppos_test` 的測試公司跑,正式資料庫不可以(owner 2026-10-09:舊庫存不搬,重新盤點)。2026-10-09 起指令自己有保護:`--tenant` 一定要給(以前預設 1 號公司);那家公司有東西會被刪時,`--confirm` 之外還要 `--wipe-company 公司代碼`(要打對),不然不做、並列出會刪掉什麼。`manage.py import_legacy_inventory`(catalog)= 商品 / 序號 / 庫存;`manage.py import_legacy_members`(parties)= 會員主檔,phone 為 dedup 鍵,`--update-existing` 可同 phone 更新;`manage.py import_legacy_purchases`(sales)= 會員消費紀錄。所有 import 預設 dry-run,加 `--confirm` 才寫入。CSV 樣本放 `docs/legacy-*-sample.csv`

### 舊系統資料(歐睿)

**2026-10-09 owner 定的範圍:舊會員帶進來、一位建一位新會員(`manage.py bring_in_legacy_members --tenant 公司代碼`,預設試算、可重跑、`--undo` 收得回來;規則在 `legacy/mapping.py` 的 `bring_in_members`),舊消費是快照、掛在會員底下、用會員電話查;舊的調撥 / 銷貨 / 進貨單不搬,庫存重新盤點。** **2026-10-14 改(12/1 啟用準備,owner「照你建議」):舊系統有庫存的品項整批建成品號** —— `manage.py bring_in_legacy_products --tenant 公司代碼 --report 商品價格查詢表.xls --mapping 類別對照表.xlsx --cost 存量金額表.xls`(預設試算、可重跑、`--undo` 收回沒用過的;規則在 `legacy/products.py`):品名照舊系統原文、**舊品號放條碼**(舊貼紙照刷;`T + 13 碼` 的另記那 13 碼當條碼別名)、售價 = 舊系統零售價(四捨五入)、**成本 = 舊系統存量金額表的成本,放在商品的平均成本**(到分;沒有的是 0)—— **盤點作業核准時門市沒有過的商品就用它入庫,所以配件的第一次入庫就是一張盤點單**;**不帶數量**(盤點時刷舊貼紙打數量);類別照 owner 2026-10-05 填的類別對照表(填排除的、對照表沒有的不建、列出來;維修料放零件倉);手機、中古機不在這裡建(盤點時刷序號);系統裡已經有同一個條碼的對照過去不另外建,同名不同條碼的不建;每一筆記在舊品號對照(`LegacyProductMap`,方式「用舊資料建立」)。讀得懂歐睿匯出的網頁表格(Big5、表頭重複)與真的 xlsx,庫存明細表(沒有售價)也認。 `apps/legacy/`:十年會員消費封存匯入(`manage.py import_legacy_history`,預設試算、寫入要 `--confirm`,有來源差異要 `--reconciled-only`,可 `--rollback`)。**原文不改**(編號空白 / Tab / 前導零、空白單價存 NULL、帶正負號金額),金額以「分」整數存,原始額與淨額(單別正負 `NET_SIGN`)分開。舊店名 / 品號 / 業務員 / 會員 → MP 門市 / 商品 / 業務員 / 會員的**對照由人確認**(`LegacyStoreMap` / `LegacyProductMap` / `LegacySalespersonMap` / `LegacyMember.member`,決定記在 `LegacyMappingLog`);明細透過 `store_map` / `product_map` / `salesperson_map`(不佔欄位的 ForeignObject)串到對照,改對照不改明細。只供查詢,不過帳、不參與上次成交價。品號對照與之後的庫存搬家共用。手冊 `docs/舊POS十年會員歷史_匯入與對照手冊.md`
