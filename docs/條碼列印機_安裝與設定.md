# 條碼列印機(Argox OS-2130D)安裝與設定

> 給門市照著做的步驟。系統這一側怎麼做的、為什麼這樣做,在 `docs/decisions.md`「條碼列印機」那兩則(2026-10-06、2026-10-13)。
>
> **這一份有哪些是實際驗過的**:系統印出來每一張標籤是 45 × 25 mm、一張一頁,上下兩聯的位置與條碼都量過(用 Chrome 輸出 PDF)。
> **實機印過一次(2026-10-13,用 PDF 檔)**:字與條碼清楚、每一張的條碼都跨在撕線上;整張偏下不到 1 mm、每一張之間上下會差一點、最左邊約 1 mm 印不到。
> **條碼槍(2026-10-13 owner 回報)**:印出來的條碼都刷得過。**但不用細線**(owner:熱感紙放久會變淡、細線會掃不到)。
> **哪些還沒驗過**:驅動程式裡每個選項的名字。這要接上實機才知道,
> 下面寫的是照原廠網站的資料整理的做法,選項的名字可能跟你看到的不完全一樣;卡住就拍一張畫面給我。

## 這台機器與標籤紙

- 熱感式(不用碳帶,要用**感熱標籤紙**),203 dpi(一公釐 8 個點),最寬印 72 mm。
- 標籤紙:**寬 45 mm、高 25 mm、上下兩聯**(中間有一條撕線,撕開各自是一張 45 × 12.5 mm 的小標籤)。
- 一張標籤印兩份一樣的內容:上半一份、下半一份、上下對稱;條碼只有一個、跨在撕線上,撕開之後兩邊各留一半、各自刷得到。
- 系統用 Chrome 的「列印」把標籤送出去,所以每一台要印標籤的電腦都要先裝原廠驅動程式、設定一次紙張。

## 一、裝驅動程式(Windows)

1. 到原廠網站下載驅動程式:<https://www.argox.com/download/drivers/?type=Drivers>,
   下載 **Argox Windows Printer Driver**(原廠寫適用 Windows 7 / 8 / 10 / 11、所有 Argox 印表機)。
2. 印表機接上 USB、開電源、裝好標籤紙,執行下載的安裝程式,型號選 **OS-2130D**。
   (如果同一個型號有 PPLA / PPLB 兩種可以選,選 **PPLB**;兩種都能印,只是印表機內部用的語言不同。)
3. 裝完到「設定 → 藍牙與裝置 → 印表機與掃描器」,看得到這台印表機就好了。

## 二、設定紙張(只要做一次)

在「印表機與掃描器」點這台印表機 →「列印喜好設定」:

1. **紙張(Stock / 標籤尺寸)**:新增一個尺寸,寬 **45 mm**、高 **25 mm**,名字取「45x25」。方向選直向。
   (高度填整張的 25 mm,不是半張的 12.5 mm:中間那一條只是撕線,印表機認的是兩張標籤之間的間隔。)
2. **紙張種類**:有間隔的標籤(Labels with gaps / 間隙)。不要選連續紙。
3. **列印方式**:熱感(Direct Thermal)。
4. 濃度(Darkness)與速度先用預設;印出來太淡再把濃度往上調一兩格。
5. 按「確定」存起來。

接著讓印表機認一次紙(校正):照原廠使用手冊「Printing Media Calibration」那一節做(手冊第 8 頁附近;
驅動程式的工具頁通常也有「校正 / Calibrate」可以按)。校正完按一下出紙鍵,應該剛好走一張標籤、停在撕紙的位置。

## 三、印測試標籤

兩種印法,印出來是一樣的四張:

- **從系統印**:登入系統 →「系統設定」→「標籤」→ **列印測試標籤**。會另開一頁,並跳出 Chrome 的列印視窗。
- **從檔案印**(系統還沒裝好、或想先對位置):用 Chrome 或 Edge 打開 `MP_POS測試標籤_45x25.pdf`,按列印。

列印視窗裡:

- **目的地**:選 Argox 那一台。
- 點「更多設定」:
  - **紙張大小**:看得到就選「45x25」;看不到這一格就不用管。
  - **邊界**:選「無」。
  - **縮放比例**:「預設」(100)/「實際大小」。**不要**選「符合頁面大小」。
  - **頁首及頁尾**、**背景圖形**:都不要勾。

印出來四張,各看一件事:

| 第幾張 | 要看什麼 |
|---|---|
| 1 四邊有框線 | **四條線都要完整**(哪一邊不見就是那一邊被切掉);左右兩邊各有一小段橫線,**要剛好落在撕線上**。拿槍刷得出 `TEST1234` |
| 2 手機 | 真的標籤的樣子:品名、進貨單號與日期、成色、售價、序號末 5 碼、品號。拿槍刷得出 `356789012345671` |
| 3 配件 | 長的品名整個印得進去(字會壓扁一點);拿槍刷得出 `4710007836224` |
| 4 長序號 | 12 碼英數的序號:條碼放不下,**沒有條碼**、整串序號印成字(末 5 碼粗體)。平常太長的序號印出來就是這樣 |

每一張都撕開來,上半、下半各刷一次。

### 印出來偏了:位置微調

測試標籤那一頁(要從系統開,PDF 檔調不了)上面有一排「位置」:**往上 / 往下 / 往左 / 往右 / 歸零**。

- 印出來偏下(第 1 張左右的短線在撕線下面)→ 按「往上」;偏上 → 按「往下」。一下是 0.25 mm,旁邊會寫現在推了多少(例「上 0.75 mm」)。
- 按完再印一次第 1 張,看短線有沒有壓到撕線;差不多就好 —— 這台機器每一張本來就會上下差一點(實測約 1 mm 以內),條碼是跨著撕線印的,差這一點兩邊都還刷得到。
- **調好會記在這台電腦上**(記在瀏覽器裡),之後這台電腦印的每一張標籤都照調過的位置。換一台電腦、換瀏覽器、清掉瀏覽器的資料要重調一次。
- 平常的列印頁有調過時會寫「位置 上 0.75 mm」,要改回到測試標籤那一頁改。

Chrome 會記住這台印表機與這些設定,之後按「列印標籤」只要再按一次「列印」。

列印頁什麼時候會自己跳出列印視窗:100 張以內、而且上面沒有要提醒的事。
張數很多、或上面有橘色的提醒(少印了幾台、條碼印不下)時不會自己跳 —— 看過之後自己按右上角的「列印」。

## 四、平常怎麼印

| 要印什麼 | 在哪裡 |
|---|---|
| 一張進貨單的全部(每一台 / 每一件一張) | 進貨入庫 → 進貨單清單 → 點那一張 → **列印標籤**。配件的張數可以在列印頁上面改(0 = 不印) |
| 某一台(標籤掉了、舊庫存沒貼) | 商品庫存 → 庫存查詢 → 點那個商品 → 那一台後面的 **標籤** |
| 某個配件、自己打幾張 | 商品庫存 → 庫存查詢 → 點那個商品 → **列印標籤** → 打張數 → Enter |
| 剛收進來的中古機(個人收購) | 存完之後畫面上的 **列印標籤** |

每一聯上面有(從紙的外緣往中間的撕線):

1. 品名(一行;太長會把字壓扁,再放不下才切掉尾巴)。
2. 進貨單號 · 進貨日期(中華民國年月日連著寫,例 `1151006`),右邊是成色(中古機)與售價(中古機是那一台自己的售價)。
3. 左邊:有序號的印「序末」加序號的**末 5 碼**;配件印條碼的那一串數字。右邊:品號。
4. 條碼(跨在撕線上)。

條碼印的是:有序號的印整支序號(有 IMEI 印 IMEI,沒有才印 SN);沒有序號的印原廠條碼;都沒有就印品號。
- 原廠條碼太長、印不下時,**改印品號的條碼**(刷品號一樣找得到),列印頁上面會講。
- 序號太長印不下(英數混合超過 10 碼的 SN)時只印文字、沒有條碼(整串序號都印出來),列印頁上面會講。
- **不用細線**把長的序號硬塞成條碼:熱感紙放久會變淡,細線先掃不到(owner 2026-10-13)。

## 五、印出來不對的時候

| 狀況 | 多半是 |
|---|---|
| 四邊的框線少一邊、內容偏一邊 | Chrome 的邊界不是「無」,或紙張尺寸不是 45 × 25;再不行就重新校正一次 |
| 左右的短線沒有對到撕線(上下偏) | 用測試標籤那一頁的「位置」往上 / 往下推(上面那一節)。每一張本來就會差一點,1 mm 以內不影響使用(條碼是跨著撕線印的) |
| 第 1 張左邊那條框線沒印出來 | 這台機器最左邊約 1 mm 印不到,正常;字離邊 1.5 mm,不會被切 |
| 整張變小、擠在左上角 | 縮放比例選到「符合頁面大小」,或紙張大小是 A4 之類的 |
| 每印一張中間多跳一張空白 | 驅動的紙張高度不是 25 mm(填成 12.5 也會)、或紙張種類選成連續紙;重新校正 |
| 條碼的線有粗有細、槍刷不到 | 縮放比例不是 100;或濃度太淡 / 太濃(往中間調) |
| 最後一張底下多一條細線 | 列印視窗的「背景圖形」被勾起來了,取消 |
| 字很淡 | 濃度往上調;確認用的是感熱標籤紙(指甲刮一下會變黑的那種) |
| 完全沒反應 | 目的地沒有選到 Argox 那一台;或印表機亮紅燈(缺紙 / 上蓋沒蓋好) |

## 六、Mac(之後要接的時候)

原廠有 macOS 的驅動程式(同一個下載頁的 **Argox macOS Printer Driver**;M1 之後的 Mac 原廠寫要先裝 Rosetta 2)。
做法一樣:裝驅動 → 在「系統設定 → 印表機與掃描器」加這台 → 紙張設一個 45 × 25 mm 的自訂尺寸 → 用 Chrome 印測試標籤。
**這一段完全沒有在實機上試過**,要接的時候再一起走一次。
