## 1. 要改善的結果

全站要讓使用者一眼分清「換工作區、篩選資料、選擇對象、改設定、執行動作、查看狀態」。相同用途採同一套控制，不再每頁自製分頁鈕、膠囊鈕、×、開關或下拉外觀。

目前 `.btn` 與 `.wb-btn` 已共用基礎樣式，應保留並逐步封裝。這次的核心工作是補上用途與狀態契約，並處理仍散落在各頁的變體。**禁止直接大量取代 class 或重寫整張 `styles.css`。** 現有 `cssCoverage.test.mjs` 的註解已記錄過刪掉 138 條規則而測試仍全綠的事故，不能重演。

先以「分層工具列」作為三張使用者截圖的修改基準：頁籤底線、帶欄名的選擇器、狀態獨立。常用少量選項可保留一次點選的單選列；不為了整齊增加門市操作步驟。

## 4. 三張截圖的具體修改

### 4.1 廠商叫貨

- 「叫貨／紀錄／對照」：同一個 Tabs，用文字與底線表達工作區。
- 「門市」「廠商分類」「廠商」：具欄名的緊湊工具列；分類下拉影響廠商名單。少量且高頻的廠商可採標準單選列，但不能另造大膠囊鈕。
- 「未開通／已停用／限管理」：獨立 Badge＋必要原因；被限制的廠商仍可選來看原因，不一律 disabled。
- 切分類時，原廠商若仍在清單中就維持；同廠商跨分類仍共用購物車。草稿仍按帳號×門市×廠商隔離。
- 無叫貨權限時不補出叫貨入口；對照不等於下單，紀錄不等於收貨確認。
- 驗收：全部→保護貼→全部、換門市、換廠商、有草稿、無權限、未開通逐一測；不擴張廠商 API 功能。

### 4.2 維修清單

- 狀態八個選項保持 Select；維修方式「全部／自修／委外」可用三項 SegmentedControl。
- 「只看返修」「只看逾期」保留可同時套用的 Checkbox；條件摘要和清除沿用。
- 搜尋 Enter 才查、其他篩選即時套用的既定行為保留；一般逾期與委外逾期不混同。
- 驗收：篩選只改清單，不改維修單狀態；焦點框與目前選項分開；首頁帶入門市仍正確。

### 4.3 舊資料對照

- 「會員／店別／品號／業務／待核」用同一 Tabs；搜尋和對照狀態用共用 Field／Select，不再出現瀏覽器原生粗框與自訂控制混搭。
- 「待核」是案件工作區，不是未對照篩選；數量若顯示必須取真實資料。
- 驗收：切工作區不確認對照／不結案；管理員限制、人確認候選、理由與新證據要求全部保留。

| 檢查層 | 實作內容 | 證明有攔截的方法 |

| JSX 使用政策 | `src/lib/controlsPolicy.test.mjs`；用現有 TypeScript parser 掃原生／動態 class／inline 外觀、複製 switch、圖示名稱、非原生互動容器 | fixture 新增一顆頁面自製藍按鈕、無名稱 ×、動態 inline 樣式都必須紅；改用共用元件轉綠 |
| CSS 政策 | 共用 token 與角色外觀只在指定共用層；具名例外按 selector／檔案範圍登記 | fixture 加頁面專屬 radius/color／移除 focus 狀態會紅；純版型 gap 不誤報 |
| 既有基線 | 記錄尚未遷移的位置及原因，使用結構指紋而非單純行號；只減不增 | 移動行號不洗掉違規；新增舊 class 不能藉整份重產基線放行 |
| 元件行為 | Tab鍵／方向鍵、開關失敗復原、pending防重入、圖示名稱、Dialog焦點、列內輸入、submit | 測使用者行為與請求數，不只比對 JSX 字串；移除修正後該案例會失敗 |
| 真實樣式 | 小型本機元件展示頁＋代表路由瀏覽器測試，覆蓋 theme/viewport/focus/state | computed style 與截圖都檢查；動態 class／CSS 被覆蓋也能發現 |
| 執行入口 | 接 `npm test`、型別檢查與建構；部署前獨立 gate；若補 CI，CI 同樣跑 | 當任一檢查紅，不能只 build 通過就部署；現有 `ops/deploy-test.sh`／`deploy.sh` 只 build 的缺口補進流程 |

現有 `cssCoverage.test.mjs` 保留；它只驗固定 class 名存在，不能用它宣稱 focus、尺寸、動態 class、ARIA 或公開報價頁已合格。本次沒有新增或執行上述 CI／產品測試，這些是 B0 的必交付項目。

### 代表流程最低集合

1. **銷貨／進貨／調撥**：連刷→改量→選付款或序號→更多→返回→提交狀態；掃碼 Enter 不觸發結帳，查圖不加入商品。
2. **盤點**：手機送出／未知結果／重送／結束；桌面群組部分選取；操作員與核准者分開驗，盲盤期間不顯示帳上缺少品、數量與差異。
3. **主檔與電信**：來源分類、會員編輯、商品批次、SIM 表單、電信列勾選／佣金欄；未存保護與送出中關閉策略測完整。
4. **三張截圖**：各測至少一個非空清單、長名稱、未開通／無權限、失敗狀態，不只看初始空畫面。
5. **報表**：改日期未查→查詢→匯出；檢查表格與匯出的已套用條件一致。
6. **管理設定**：即時開關延遲／失敗／重試；待儲存 Checkbox 不立即寫入；取消編輯不執行移除。
7. **列印與手機拍照**：列印取消後可重試，no-print 生效；原紙張尺寸不變。紙張版面若有實際變動，需門市印表機實印，預覽不能取代。
