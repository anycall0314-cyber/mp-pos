# 批發(同行之間互相買賣)使用步驟

> 2026-10-14。目前在測試站。**錢不經過系統**:系統只記誰跟誰買了什麼、出了沒、還欠多少。
> 兩家都用這套 POS 的經銷商才能這樣用(對外面的系統用金鑰的接法還沒做)。

## 賣家(要批發給同行的那一家)

### 第一次:開起來(管理員,只做一次)

1. 左邊「銷貨作業」→ 上面「批發單」→ 右上角「設定」。
2. 「開放批發」選開。其他先照預設就可以:
   - 批發算法:中古機的批發價怎麼算(門市售價減多少 / 打幾折 / 收購價加多少)。每一台自動算好,之後可以個別改。
   - 進貨上架:開著 = 中古機一進貨(或跟客人收購)就上架,不用另外按。
   - 平台販售:開著 = 平台上每一家同行都看得到你的中古機;關掉 = 只給你核准的同行。
   - 下單接單:開著 = 同行下單就算接單。
3. 按「儲存」。

### 讓一個同行可以跟你買全新機與配件

1. 「批發單」→「同行帳」→「發往來代碼」。畫面出現八碼。
2. 把這八碼傳給對方(LINE、電話都可以)。七天內有效、只能用一次。
3. 對方輸入之後,他就出現在「同行帳」;折數(門市價的百分之幾)與付款方式可以直接在那一列改。

### 對方不在這套系統上(他有自己的系統或程式)

1. 「批發單」→「同行帳」→「加外部同行」→ 填名稱與怎麼聯絡 →「發金鑰」。
2. 畫面出現一個網址與一把金鑰,**只顯示這一次**。按「複製」傳給對方。
3. 弄丟或外流:那一列「換金鑰」(要按兩下),舊的立刻不能用。
4. 他下的單一樣出現在「待出貨」,標著「對外」與聯絡方式。不是月結的,出貨那一排會提醒「未收款 還差多少」(只是提醒,照樣可以出)。

### 哪些東西要批發

- 中古機:自動上架。價錢靠**價目表** →「批發單」→「中古機」:
  1. 先看到型號清單:一列一個型號,寫在庫、未上架、上架中、被訂走、獨立價各幾台,**最右邊就是這個型號的價目**。
     行情變了:直接把那幾格的數字改掉 → 按「改價」→ 畫面講幾格、全公司幾台會變 → 再按一次。不用點進去。
  2. 第一次定價目:點型號 → 上面點**成色**、填**電池**最低 / 最高、點**有備註 / 沒備註** —— 點的就是價目的那一格(例:A 級 沒備註)
     → 在「價目」打價 → 按「改價」→ 再按一次。全公司符合這一格的都用這個價(不只畫面上這幾台),之後進貨的也是。
  3. 特殊的那幾台:把它前面的勾拿掉(= 獨立定價),或在它那一格直接打自己的價。之後價目怎麼改都不動它。
     要它回來跟價目:把勾打回去。「獨立價」那一顆可以只看獨立定價的那幾台。
  4. 未上架那一頁按「上架」、上架中那一頁按「下架」:動的是畫面上列出來的每一台(先用篩選挑)。
  - 「紀錄」:這個型號每一次改價 —— 誰、什麼時候、哪一格、幾台、從多少到多少。打序號只看那一台的。
  - 價目是全公司的,只有沒被鎖在一間門市的帳號能改;店員可以替自己門市的那一台定獨立價。
  - 有一台剛好被賣掉:整批都不動,畫面講是哪一台,清單會自己更新,再按一次就好。
- 全新機與配件 →「批發單」→「批發品」→ 切到「全部品」→ 勾「批發」。有填「固定價」的每一個同行都是那個價錢;沒填就是門市價 × 他的折數。

### 出貨(店員也可以;帳號要有「批發出貨」)

1. 「批發單」一進來就是「待出貨」。
2. **直接刷那一台**,不用先找是哪一張單 —— 系統自己找、打勾。刷不到碼的,在那一行勾「出」。
3. 配件的數量預設就是還沒出的全部,要少出就改數字。
4. 找不到的那一台按「不出」(要按兩下),其餘的照樣出。
5. 要收運費就填「運費」,有託運單號就填,按「出貨」。系統自動開一張銷貨單、扣庫存。
6. 出錯了:「全部單」→ 點那張單 →「取消出貨」(要按兩下)。貨回到庫存、銷貨單作廢。
   **對方已經入庫的不能取消**(同一批貨不能兩家都在庫):請對方先把那張進貨單作廢,你這邊才取消得了。

### 同行訂走的那一台,現場客人也要

照平常開銷貨單、刷那一台、結帳。系統會問:

- 「賣給客人」:這一台賣給現場客人,同行那一台當下取消(對方看得到)。
- 「留給同行」:不賣,自己把那一台從明細拿掉。

### 收到同行的錢(管理員)

「批發單」→「同行帳」→ 那個同行的「收款」→ 填收到多少 →「記一筆」。
系統由舊到新把他的單銷掉,看得到還欠多少、多收多少。記錯了按那一筆的「作廢」。

## 買家(要跟同行買的那一家)

還欠對方多少:「廠商叫貨」→「紀錄」→「看對帳單」(對方算的)。

### 第一次:加入(管理員)

- 對方給了往來代碼:「系統設定」→「叫貨串接」→ 最上面「加入同行」→ 輸入八碼 →「加入」。每一間門市自動開通。
- 對方有開平台販售、你只是要買它的中古機:「叫貨串接」→ 找到那一家 →「開通」選開通叫貨 →「儲存」。
- 要宅配的話,在那一家的卡片把收件人、電話、地址填好。

### 叫貨

1. 「進貨入庫」→「廠商叫貨」→ 上面選那個同行。
2. 中古機一列一台(成色、電池、備註寫在品名後面),要哪一台就勾「訂」。其他商品填數量。
3. 「確認叫貨」→「送出叫貨」。
4. 對方還沒出貨之前可以取消:「紀錄」→ 點那張單 →「取消叫貨」(要按兩下)。

### 貨到了

1. 「紀錄」→「更新進度」→ 那張單的「到貨入庫」。
2. 手機那幾行已經列好對方出的每一台(序號、成色、電池),**不用再刷一次**。
3. 第一次要選「入到哪個品號」(中古機選自己的中古機商品、全新機選全新機商品)。選過一次之後會記住。
4. 「確認入庫」。系統開一張進貨單,那幾台直接進你的庫存。
5. 對方還沒出的不能先入。要退貨:先把這張進貨單作廢,對方才取消得了那一次出貨。
